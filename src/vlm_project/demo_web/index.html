Kết nối Kaggle worker

TRẠNG THÁI WORKER Đang kiểm tra kết nối Chưa nhận được tín hiệu từ worker

Worker Kaggle lấy yêu cầu từ gateway local, chạy model và gửi kết quả về qua HTTPS.

  1. Lấy URL HTTPS từ log tunnel. Gateway mặc định: http://127.0.0.1:8766.
  2. Lưu URL vào Kaggle Secret DEMO_BROKER_URL.
  3. Lưu mã phiên vào DEMO_WORKER_TOKEN; cấp quyền cả hai Secrets cho notebook.
  4. Bật GPU và Internet, chạy notebook worker.

Token thay đổi khi server khởi động lại. URL Quick Tunnel có thể thay đổi sau khi tạo lại tunnel.
