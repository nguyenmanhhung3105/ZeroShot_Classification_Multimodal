HẠ TẦNG SUY LUẬN

Kết nối Kaggle worker

TRẠNG THÁI WORKER Đang kiểm tra kết nối Chưa có thông tin heartbeat

Gateway local nhận yêu cầu; worker Kaggle thực hiện suy luận và trả kết quả qua HTTPS.

  1. Lấy URL HTTPS từ log tunnel. Gateway mặc định: http://127.0.0.1:8766.
  2. Gán URL cho Kaggle Secret DEMO_BROKER_URL.
  3. Gán mã phiên cho DEMO_WORKER_TOKEN; cấp quyền cả hai Secrets cho notebook.
  4. Bật GPU và Internet, chạy notebook worker.

Token thay đổi khi server khởi động lại. URL Quick Tunnel có thể thay đổi sau khi tạo lại tunnel.
